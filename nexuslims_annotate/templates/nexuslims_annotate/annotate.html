How to Annotate

Annotating a record lets you attach plain-language descriptions to each dataset (file) captured during an experiment. These descriptions appear alongside the data in the gallery and activity tables, making it easier for collaborators to understand what was acquired and why without having to open every file. They are also attached to the structured record, and will be included if you download the XML or JSON of the record.

Adding Descriptions
  • Type a description in any text box and click Save Annotations to save all at once.
  • Press Ctrl+Enter (or Cmd+Enter on Mac) to save without using the button.
Color Coding
Green — description saved
Orange — unsaved change
Gray — no description yet
