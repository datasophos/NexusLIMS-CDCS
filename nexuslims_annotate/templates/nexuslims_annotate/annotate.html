    How to Annotate

    Annotating a record lets you attach plain-language descriptions to each dataset, reassign datasets to different acquisition activities, manage samples examined during the experiment, and add or remove acquisition activities. All changes save together when you click Save Annotations.

    Managing Samples
    • The Samples panel at the top shows all samples for this record.
    • Click Add Sample or Edit to open the sample editor (name, description, notes, elements).
    • Use the dropdown in each activity header to assign a sample to that activity.
    • Deleting a sample that is assigned to activities will prompt for confirmation.
    Managing Activities
    • Click + below in an activity header to insert a new activity below it.
    • Click + Add Activity in the save row to append a new activity at the end.
    • The trash icon button in an activity header deletes it (only enabled when the activity has no datasets).
    Adding Descriptions
    • Type a description in any text box and click Save Annotations to save all at once.
    • Press Ctrl+Enter (or Cmd+Enter on Mac) to save without using the button.
    Moving Datasets
    • Drag any dataset card to a different activity section to reassign it.
    • Check one or more cards (or Shift-click to select a range), then use the Move to Activity toolbar to batch-move them.
    • Drag a selected card to move all selected cards together to a new activity.
    • Click the Moved badge on a card to undo that move before saving.
    • Moves are saved together with descriptions when you click Save Annotations.
    Color Coding
    Green — description saved
    Orange — unsaved change
    Gray — no description yet
    Indigo — pending move (not yet saved)
