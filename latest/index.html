NexusLIMS CDCS#

NexusLIMS CDCS is the frontend for NexusLIMS. It provides a web-based platform for searching, visualizing, and managing the experimental records generated by the NexusLIMS backend.

Prefer to explore for yourself rather than reading documentation?

Try the Live Demo →

Looking for the main NexusLIMS documentation?

Heads up! This documentation site is for the frontend web application bundled with NexusLIMS. If you are interested in the main NexusLIMS application that extracts metadata and builds experimental records, please see the main documentation site.

Key Features#

  • Search and explore records using full-text and structured queries.

  • Visualize experimental data with previews, metadata, and downloadable files.

  • Curate datasets with descriptions, ratings, and featured selections.

  • Display a public gallery of preview images for your facility.

  • Manage and integrate data through user permissions and a REST API.
