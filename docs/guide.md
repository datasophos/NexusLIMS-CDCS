# Frontend guide

NexusLIMS-CDCS is the web frontend for NexusLIMS. It is a customized version of
the [Configurable Data Curation System](https://cdcs.nist.gov/) developed by NIST.
This guide covers deploying, configuring, administering, and troubleshooting CDCS.

```{note}
NexusLIMS-CDCS is maintained by [Datasophos](https://datasophos.co) and is
**not affiliated with NIST**.
```
