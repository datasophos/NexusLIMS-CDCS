# Viewing Records and Data

A record detail page brings together the experiment summary, samples, acquisition
activities, datasets, and metadata. Preview images and links to instrument files
help you inspect the data associated with an experiment.

```{figure} ../images/cdcs/04_detail_top_matter.png
:alt: Experiment record detail view
:width: 100%

The record detail view presents the experiment and its metadata.
```

## Samples and acquisition activities

Records containing multiple samples show a card for each sample with its name,
identifier, description, and elemental composition when available. Acquisition
activity headers link to the associated sample. Within each activity, datasets
are grouped with their previews and technical metadata.

```{figure} ../images/cdcs/15_detail_multisample_cards.png
:alt: Sample cards and their acquisition activities
:width: 100%

Sample cards and activity badges help connect datasets to their samples.
```

## Dataset metadata and files

Dataset tables show technical metadata such as voltage, magnification, or other
values extracted from the instrument files. Use the file downloader to select
and download multiple data files and metadata together. For very large records,
a simplified display helps keep the page usable.

```{figure} ../images/cdcs/07_detail_file_downloader.png
:alt: File downloader interface
:width: 100%

Select files for a bulk download from the record detail page.
```
